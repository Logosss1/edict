# Code of Conduct

## Our standard

We want Edict_InnerCourt to be a useful and respectful open-source project. Participants are expected to:

- be welcoming and constructive;
- discuss ideas and code without personal attacks;
- respect different backgrounds, experience levels, and viewpoints;
- accept good-faith technical criticism;
- focus on what is best for users and the project;
- protect private information and avoid sharing credentials or private runtime data.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, doxxing, publishing private information, and knowingly submitting malicious code or credentials.

## Enforcement

Maintainers may edit, remove, or close contributions that violate this policy and may restrict participation when necessary. Report conduct concerns privately through the repository maintainer's GitHub contact. Do not use public issues to disclose security vulnerabilities; use [SECURITY.md](SECURITY.md) instead.

This code of conduct applies to the repository, issues, pull requests, discussions, and project-related communication.
